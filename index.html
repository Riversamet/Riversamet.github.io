Machine learning · Random Forests · MLPs

Catalyst Performance Prediction

This project is used to predict electrocatalytic activity in the hydrogen evolution reaction through classification with random forests and regression with multilayer perceptrons.

  • Random forest classification reached a test F1 of 0.76 after tuning, with similar scores across the other two splits; tuning minimized overfitting by narrowing the F1 training-validation gap
  • MLP regression reached a test RMSE of 0.11, with errors consistent across all three splits
